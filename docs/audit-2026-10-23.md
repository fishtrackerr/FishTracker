# Audit 2026-10-23: fix plan

Scope: a personal, offline-only app (no backend). The findings are ranked by how likely they are to lose data or break something you use every day. A path written as `file:line` points at the code as of commit `d9919a3`.

## Phase 0: Package updates (done on branch `chore/update-deps`)

- `npm update` installs the newest patch release in each current range: Angular 21.2.25 / build 21.2.28, Capacitor 7.6.9, Dexie 4.4.6, Vitest 4.1.12, typescript-eslint 8.72, Prettier 3.9.10.
- Runtime dependency advisories (Angular XSS/sanitization, Capacitor Android proxy (critical)): 9 → **0**.
- Removed `to-ico`, the source of the old jimp/request chain with critical advisories. `scripts/generate-pwa-icons.mjs` now writes `favicon.ico` itself. `sharp` is now 0.35.5 (libvips CVEs).
- Dev advisories: 53 → 6. What remains is one `braces` advisory inside `angular-cli-ghpages`. It is deploy-only and has no fix yet.
- Lint, tests and build give the same results as before the update.

## Phase 4: Tooling / release

- Fix lint (2 errors: `app-version.service.ts:16`, `session.service.ts:269`; 5 unused imports) and remove `continue-on-error` from CI. HTML is not actually linted; consider angular-eslint.
- `npm run deploy` tags **before** the version bump is committed. As a result `v0.0.53` points at a commit that still says 0.0.52, and the release notes shift by one version. Fix: commit in `set-version.js` before tagging, or refuse to tag when the working tree is dirty.
- CI runs `npm run icons` twice.
- The initial bundle is 924 kB against a 600 kB budget. Find out what is eager (Material modules in the shell, fonts/icons) and lazy-load it, or set the budget to a realistic value.
- `tsconfig.app.json` `"types": ["node"]` should be `[]`.
- Android: remove `READ_MEDIA_IMAGES`/`READ_EXTERNAL_STORAGE` (not needed for the file picker; Play flags them).
- npm 12 blocks install scripts (esbuild, sharp, lmdb…). It works now through prebuilt binaries; if needed, add `allowScripts` to package.json.
- Tests: 3 `mql.addListener is not a function` errors show up now and then (CDK BreakpointObserver under jsdom). Add a `matchMedia` stub to the test setup.

## Phase 6: Major upgrades (separately, one at a time)

1. **Angular 22** (+ Material/CDK 22): `ng update @angular/core@22 @angular/cli@22 @angular/material@22`. Let the migrations run, then lint/test/build.
2. **Capacitor 8**: requires newer Android Gradle/SDK versions. Follow the Capacitor 8 migration guide, use `npx cap migrate`, and test on a device. Combine this with the filesystem/share plugins from item 1.
3. **ESLint 10** + `@eslint/js` 10 (flat config is already in place), **Vitest 5**, **jsdom 30**, `@types/node` → match your Node version (24).
4. **TypeScript 7**: only once Angular officially supports it (follows from step 1).
